# AI Cheatsheet Generation Pipeline

A sophisticated backend pipeline that generates original, unique cheatsheets using AI. The pipeline takes either text prompts or uploaded cheatsheet images and generates completely new, non-plagiarized content with regenerated visualizations.

## 🎯 Features

- **Dual Input Modes**: Generate from text prompts or existing cheatsheet images
- **Content Generation**: Uses Gemini Flash API for high-quality text content
- **Image Analysis**: Analyzes uploaded cheatsheets using Gemini Nano API
- **Image Generation**: Creates new visualizations using image generation APIs
- **Originality Guarantee**: Completely regenerates content to avoid plagiarism
- **Multiple Formats**: Output as PDF, HTML, or PNG
- **Comprehensive Pipeline**: End-to-end orchestration of all components
